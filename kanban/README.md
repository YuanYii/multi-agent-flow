# Multi-Agent Flow · 纯静态离线看板 (Pure Static MVP)

> **版本**：`release_v5_mvp`  
> **特性**：**零服务端依赖**、**零端口占用**、**双击即开即用**，纯前端 JavaScript 驱动与 JSON 文件读写。

---

## [START] 快速使用 (双击即用)

1. **直接打开**：
   - 用任意浏览器（Chrome / Edge / Safari / Firefox）直接双击打开 [`offline_board.html`](offline_board.html)；
   - 或在浏览器地址栏直接输入相对路径：`file:///.../kanban/offline_board.html`。

2. **本地文件读写与持久化**：
   - **自动缓存**：看板在浏览器的所有拖拽、修改、新增与流转均会自动保存在浏览器本地存储（`localStorage`）中；
   - **导出备份 (`board.json`)**：点击工具栏的 **【导出 JSON】** 按钮，一键将当前全部任务生成标准的 `board.json` 并下载到本地；
   - **导入载入 (`board.json`)**：点击工具栏的 **【导入 JSON】** 按钮，选择任意本地 `board.json` 即可秒级还原与无缝切换工单。

## 核心能力清单

- **4 大视图**：数据表格视图、看板-按状态视图、看板-按负责人视图、看板-按阶段工作包视图；
- **全生命周期流转追溯**：支持任务属性卡片、状态标签彩色渲染、全流程历史日志与始终显示的精细滚动条；
- **双模拖拽联动**：拖拽卡片或在表格快捷变更状态时，自动弹出流转说明对话框并追加带时间戳的审计流水；
- **深浅主题自适应**：支持日落自动算法切换与手动一键切换深色/浅色模式；
- **初始演示种子**：内置标准初始任务 **T0000**（钱架构 / 架构分析 / 进行中状态）。
