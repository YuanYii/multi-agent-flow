# Multi-Agent Flow · 可视化看板 (Kanban)

> **特性**：**双模支持**（纯静态离线直接打开 / 本地与局域网 Web 服务）、**Master RBAC 权限分立**、**4 大核心视图**、**全流程审计追溯**。

---

## 🚀 快速使用

### 模式 A: 本地与局域网 Web 服务（推荐）

```bash
# 全平台启动命令（自动探测 32886–32905 空闲端口并输出访问链接）
python3 scripts/start_kanban_server.py
```
- **本地直达**：`http://127.0.0.1:32886/`
- **局域网协同**：`http://<局域网IP>:32886/`（脱敏纯净链接，支持团队受控接入）
- **主控鉴权**：启动控制台输出一次性动态 🔑 Master Token。

### 模式 B: 纯静态离线使用（免服务）

用任意浏览器直接双击打开 [`offline_board.html`](offline_board.html) 即可。支持 `localStorage` 自动缓存与 `board.json` 一键导入/导出。

---

## 🌟 核心能力清单

- **4 大视图模式**：数据表格视图、状态泳道视图、负责角色负载视图、阶段工作包视图；
- **Master RBAC 权限分立**：主控端掌控全生命周期与阶段结项；协作者受控推进并拦截终态逆流；
- **全生命周期流转追溯**：状态变更自动弹出流转说明对话框并追加带时间戳的不可篡改审计流水；
- **深浅主题自适应**：支持跟随系统及手动一键切换暗黑/明亮主题。
