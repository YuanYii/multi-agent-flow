WHY MULTI-AGENT FLOW

告别“盲目点 YES”，重塑工程主导权

在 Vibe Coding 时代，单 Agent 往往既当裁判又当运动员。Multi-Agent Flow 通过多角色交叉制衡与代码级门控，让每一次交付都经得起工程检验。

传统单 Agent · 沦为盲从的“YES 工程师”
黑盒生成 · 缺乏制衡 · 越权篡改 · 虚假完成
✕

自己写自己审，开发者疲于点 Accept

单 Agent 生成动辄数百行 Diff，人类精力有限无法逐行审阅，只能盲目点 YES，隐藏 Bug 频频带入生产。

✕

无代码级硬门禁，越权篡改核心配置

单 Agent 拥有全量写权限，随意更改全局配置、静默修改历史记录，缺乏代码级防错拦截机制。

✕

秒级虚假流转，隐患黑盒累积

没有独立测试用例与时序凭据，任务在 1 秒内推向完成，交付周期全是虚假数据，后期返工成本巨大。

Multi-Agent Flow · 契约驱动的“研发指挥官”
多角色交叉制衡 · 架构技术沉淀 · 缺陷原单绑定 · 真实时序
✓

AI 内部交叉制衡，周审查与章测试替你严把关

李开发 编码后必须经 周审查 独立挑刺并由 章测试 执行端到端用例，严经理 终检验收，AI 互相监督替代人工肉眼扫代码。

✓

阶段双总结门控，沉淀组织级技术资产

阶段结项（check_stage_gate）不仅是完工核验，更强制沉淀钱架构的「技术架构总结 (ADR/负债清偿)」与严经理的「PMP 敏捷复盘总结」，拒绝“代码一交、技术清空”。

✓

缺陷原卡绑定（DEF）与心跳巡检效能雷达

测试与审查不通过原卡打回并挂载 DEF 结构化缺陷，保留初始开工时间与返工痕迹；heartbeat.py 巡检引擎自动告警瞬时冲卡与任务死锁。

CORE FEATURES

为企业级规范研发设计的协作中枢

解决 AI 编程混乱、越权篡改、上下文膨胀与任务失控的核心痛点。

十大协作红线与阶段双总结门控

严格执行越权拦截与阶段门禁（check_stage_gate）；阶段结项硬性要求钱架构输出「技术架构总结 (ADR/负债清偿)」与严经理输出「PMP 敏捷复盘总结」，沉淀团队技术资产。

缺陷打回不拆单与原卡闭环追溯

测试与审查不通过时原卡打回（【已退回】）并自动挂载 DEF-TXXX-N 缺陷单，保留初始开工时间与返工痕迹，杜绝新建孤儿卡刷完工率。

心跳健康巡检与 14+ 效能雷达

内置 heartbeat.py 自动化巡检引擎，实时探测任务死锁、在制品（WIP）超限、停滞与瞬时冲卡（TIME_SKEW_INSTANT），精确度量有效交付周期。

单人离线极速 + 团队云端适配

单人开发免依赖直接双击离线 HTML 或启动本地 Web 服务（0 Token 开销）；团队协作通过 Board Adapter 原生对接飞书多维表格、GitHub Projects、Jira 等云端大盘。

D01–D06 企业级标准文档骨架

基于 Diátaxis 架构规范，李文通 维护项目管理、架构 ADR、系统设计、研发用例、交付部署与运维全套工程骨架，内置 Frontmatter 元数据镜像。

L0–L2 任务分级与敏捷智能路由

根据任务复杂度自动三问分级：L0 轻量即时直答、L1 标准特性完整敏捷流转、L2 架构级重构强制钱架构 ADR 预研会诊，大任务严控、小任务快跑。

GitHub PR 自动合流解阻与发布

运维专家吕改特自动感知 GitHub PR Merged 状态，秒级推进【已阻塞】工单并通知 PM 验收，自动归档 Conventional Commits 与发布 Tag。

跨 AI 开发环境轻量化全移植

纯 Python 3 原生实现，0 外部数据库与 Node 依赖；通用 Skill 规范完美兼容 Antigravity、Claude Code、Cursor、Codex、Windsurf 等任意开发环境。

全自动任务流转与断点续跑

通过 /yy-flow auto 一条指令全自动执行任务完整生命周期直至已验收，支持 A–G 全类型链自动路由，中断后自动识别当前状态断点续跑。

敏感凭据安全扫描与审计追溯

初始化首步运行 check_secrets.py 扫描 Token/密钥泄露风险；全量流转操作落盘审计日志（audit_query.py），支持按 Task ID 追溯、日志轮转与 gzip 归档。

阶段双向 Git 门禁与 5 项硬核验

阶段开工准入核验前序闭环与 Git 清洁度，输出特性分支拉取向导；阶段结项执行看板全终态、WBS 双向对账、架构/PM 总结归档、工作区 Clean 与合流打 Tag 5 项硬核验。

强类型交接契约与「无工单不 Git」

Agent 间流转通过强类型 JSON Payload 结构化交接（含改动文件、覆盖率、缺陷历史）；外部 Commit/PR 保持纯净通用，内部工单与虚拟角色元数据在看板单向闭环沉淀。

SLASH COMMANDS

五大快捷指令，开箱即用

在 AI 对话中输入 /yy-flow 快捷指令即可触发对应工作流能力，无需记忆底层脚本与参数。

/yy-flow start

一键激活工作流

执行 7 步标准初始化：凭据扫描、专家导出、架构嗅探、数据落盘、文档骨架、技术栈同步与 PM 编排。

/yy-flow status

全局大盘与健康巡检

一键输出项目完成进度、交付周期 Lead Time、专家负荷与超时滞留、并发超限风险告警。

/yy-flow kanban

启动看板 Web 服务

自动探测空闲端口启动本地可视化看板（32886–32905），支持同项目实例复用与健康检查接口。

/yy-flow sync-pr

PR 监听与自动解阻

扫描【已阻塞】任务卡，检测 GitHub PR Merged 后秒级推进至【已完成】并通知 PM 验收。

/yy-flow auto

全自动单任务流转

一条指令全自动执行任务完整生命周期至已验收，支持 A–G 全类型链、断点续跑与已阻塞解阻。

💡 业务流转与协同全走自然语言：需求拆解建卡、阶段开工结项、认领、提审、测试与打回等日常研发全生命周期，直接使用自然语言与 Agent 对话沟通，由对应专家在后台自主调度底层脚本，无需记忆任何 CLI 命令。
