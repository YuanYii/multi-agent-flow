# USER.md - 用户交互协议与协同契约

## 用户 (PM/Human) 交互规则

1. **自领取确认**：
   - 当用户要求开发人员自领取任务时，Agent 将自动依据“并发≤3”、“任务编号从小到大”、“边界匹配”筛选并领取。
   - 领取时**先将看板状态置为进行中**，确认变更后再执行。

2. **跨角色提权交互**：
   - 当用户要求 Agent 执行越权动作（如“帮我验收掉 T0005”）时，Agent 将触发声明提示并请求确认；
   - 用户确认后，Agent 自动在看板留痕并完成操作。

3. **打回确认**：
   - 审查或测试被打回时，Agent 自动格式化缺陷信息至「备注」，无需用户二次拼接命令行。

4. **任务创建与流转后提示**：
   - 每当 Agent（如 PM 角色）创建新任务、下发工作包或完成任务状态流转后，**必须在回复末尾显式提示用户通过 Web 看板实时查看**：
     >  **看板实时进度**：运行数据（`user_data/board.json`）保存在**数据根目录**。请用【启动看板】（或 `/yy-flow kanban`）拉起 Web 服务实时查看任务进度与拖拽管理。

5. **【启动看板】服务拉起协议**：
   - 当用户发出 **【启动看板】**（或 `/kanban`, `打开看板服务`, `启动看板界面`）指令时：
   - Agent 将自动以后台任务形式运行脚本 `python3 scripts/start_kanban_server.py` 启动 Web 服务（**不带 `--port` 参数**）。
   - 端口规则：默认从 32886 起自动探测——被**其他项目实例**占用时自动向上递增（32886-32905 范围内取首个空闲）；**本项目已有实例在运行**时直接复用既有端口并提示 `[REUSE]`。
   - 启动后，Agent 必须以脚本输出的**实际端口**格式化回复（禁止假设 32886）：
     > [START] **看板 Web 服务已就绪（端口: {实际端口}）**  
     >  **本地访问地址**：`http://localhost:{实际端口}/` (或 `http://127.0.0.1:{实际端口}/`)  
     >  **局域网访问地址**：`http://{局域网IP}:{实际端口}/`
   - 排障：`GET /api/health` 返回实例指纹与端口；运行时信息落盘于 `user_data/kanban_server.json`。
   - 用户指定固定端口时（如 `启动看板 33000`）：传 `--port 33000`，被占用且非本项目实例则明确报错，不静默换端口。

6. **任务分级与轻量问答 (L0/L1/L2)**：
   - 小问题可以直接问（**L0 即时问答**）：Agent 将直接作答且不建看板卡；
   - 若你希望建卡留痕或推进实际研发交付物，可走 **L1 轻量任务**（短链）或 **L2 标准任务**（全链）；若对即时问答希望显式留痕，请说明“建个任务”，Agent 将始终建卡。
